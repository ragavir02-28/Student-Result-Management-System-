Student Result Management System

Web Technology Mini Project

About the Project

The Student Result Management System is designed to manage student academic records and results in an organized manner.

Project Objectives

  • Manage student information.
  • Maintain subject and examination details.
  • Enter and manage student marks.
  • Calculate total, average and percentage.
  • Generate student result reports.

Technologies Used

  • HTML5
  • CSS3
  • JavaScript
  • PHP
  • MySQL
